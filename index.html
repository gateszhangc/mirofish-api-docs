MiroFish API · v1.1.0

Run the same simulations as the MiroFish web app.

Upload source material, create a project, build its ontology and graph, run a simulation, and retrieve the report through one authenticated HTTP API.

Read the quickstart → Browse API reference
Production base URL: https://mirofish.my
The mental model

One page-equivalent workflow, made programmable.

API-created projects use the same project, graph, simulation, and report engine as the MiroFish web application. The API adds an independent prepaid credit balance so automation can run without a browser session.

Before you begin

Create an API key in your account, keep it server-side, and send it as a Bearer token on every request.

More examples ↗ 
const response = await fetch(
  "https://mirofish.my/api/mirofish/projects/PROJECT_ID",
  { headers: { Authorization: `Bearer ${process.env.MIROFISH_API_KEY}` } }
);

if (!response.ok) throw new Error(await response.text());
const { project } = await response.json();
console.log(project.status);
Credits and safety

Built for automation without hidden surprises.

  • Independent balance. API credits are shared by the account's keys and never expire.
  • Idempotent writes. Reuse an Idempotency-Key when retrying the same state-changing request.
  • Traceable responses. Authenticated responses include X-Request-Id.
  • Webhooks. Receive signed notifications for graph, simulation, and report milestones.
